# Deploy

Recommended production path:

1. Use `prof-training-site` as the project root.
2. Install dependencies with npm.
3. Build with `npm run build`.
4. Publish the generated `dist` directory or connect the repository to Vercel and set the root directory to `prof-training-site`.

Before launch, replace demo prices/hours/document wording and connect the lead form to the real backend/CRM/Telegram endpoint.
