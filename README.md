# KBKS AUTO — Design Workspace

Рабочий репозиторий для нового дизайна раздела «Автошкола» КБКС.

## Назначение

Здесь проектируется и проверяется новый интерфейс KBKS AUTO до переноса в существующий WordPress-сайт КБКС.

## Базовые правила

- Один источник истины: работающий HTML/CSS/JS.
- Статический макет не выдаётся за результат HTML-рендера.
- Скриншоты принимаются только как результат реального браузерного рендера.
- Сначала desktop/mobile interface, затем визуальная проверка, затем решение о переносе.
- Не переносить старые прототипы автоматически.
- Не использовать персонажа в текущем направлении.
- Не добавлять неподтверждённые цены, сроки, даты набора, программы или другие факты.
- Основной сайт КБКС не изменяется из этого репозитория.

## Рабочий процесс

SPEC LOCK → IMPLEMENT → BROWSER VERIFY → VISUAL REVIEW → HUMAN GATE → NEXT ITERATION

## Статус

Новый чистый workspace. Дизайн ещё не зафиксирован.
